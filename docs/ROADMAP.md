# ChessLens roadmap

- [x] Phase 0 — Vite project, architecture, and browser Stockfish smoke test.
- [x] Phase 1 — Board and play against Stockfish with adjustable strength.
- [x] Phase 2 — PGN import and full-game review with navigation and evaluations.
- [x] Phase 3 — Move classification, win probability, and accuracy.
- [ ] Phase 4 — Opening names, richer review feedback, and game imports.
- [ ] Phase 5 — Accounts, saved games, and statistics backed by Supabase.
- [ ] Phase 6 — Advanced features such as blunder training, online play, and Thai explanations.

Phase 4 รุ่นแรกส่งมอบการนำเข้าด้วย username การสรุปเกม การฝึก และเครื่องมือวิเคราะห์เพิ่มแบบจำกัดเวลา รายการที่เหลือประกอบด้วยสถิติ Opening Explorer, ธีมและชุดหมาก, เสียง, ความเร็วแอนิเมชัน, ส่งออกกราฟ และตรวจเกณฑ์ Lighthouse

Phase 5 รุ่นแรกมีโค้ดสำหรับบัญชี คลังเกม สถิติ และฝึกซ้ำ โดยใช้ Supabase
GitHub Pages เชื่อมกับโปรเจกต์ Supabase แล้ว การทดสอบสมัคร ยืนยันอีเมล และเปิดรีวิวที่บันทึกบนเว็บจริงยังอยู่ระหว่างตรวจสอบ

Phase 6C เพิ่มตัวฝึกเปิดเกมจาก PGN และเกมที่เคยรีวิว พร้อมสถิติแยกไลน์และรอบทบทวน ([วิธีใช้](OPENING_TRAINER.md))
