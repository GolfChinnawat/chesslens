# ChessLens roadmap

- [x] Phase 0 — Vite project, architecture, and browser Stockfish smoke test.
- [x] Phase 1 — Board and play against Stockfish with adjustable strength.
- [x] Phase 2 — PGN import and full-game review with navigation and evaluations.
- [ ] Phase 3 — Move classification, win probability, and accuracy.
- [ ] Phase 4 — Opening names, richer review feedback, and game imports.
- [ ] Phase 5 — Accounts, saved games, and statistics backed by Node.js and PostgreSQL.
- [ ] Phase 6 — Advanced features such as blunder training, online play, and Thai explanations.
