# Phase 6B · ห้องเล่นกับเพื่อน

ทั้งสองคนเข้าสู่ระบบ ChessLens ด้วยบัญชีคนละบัญชี คนแรกเปิด **เล่นกับเพื่อน**
เลือกเวลา 3, 5, 10 หรือ 15 นาทีต่อฝ่าย กด **สร้างห้อง** แล้วส่งรหัสห้องหรือลิงก์ให้เพื่อน
ถ้าได้รหัส ให้เปิด **เล่นกับเพื่อน → เข้าห้องด้วยรหัส** แล้วพิมพ์รหัสที่ได้รับ
คนสร้างเล่นขาว คนที่เข้าห้องเล่นดำ เวลาฝ่ายขาวเริ่มทันทีที่มีคนเข้าร่วม

กลับเข้าห้องด้วย URL เดิมจากบัญชีเดิมได้ เวลายังคงเดินเมื่อหลุดการเชื่อมต่อ
เมื่อจบเกม กด **รีวิวเกมนี้** แล้วนำเข้า PGN ที่กรอกไว้ให้ เพื่อเริ่มวิเคราะห์

## ระบบและการทดสอบ

Supabase Auth ใช้ระบุตัวผู้เล่น Edge Function ตรวจตาเดินด้วย chess.js
และหักเวลาจากเวลาฝั่งเซิร์ฟเวอร์ การบันทึกแต่ละครั้งตรวจเลขรุ่นของห้อง
Postgres RLS จำกัดการอ่านเฉพาะผู้เล่นสองคน หน้าเว็บรับอัปเดตผ่าน Realtime
และโหลดข้อมูลอีกครั้งทุก 10 วินาทีเมื่ออยู่ในห้องเป็นทางสำรอง

ใช้ migration `online_rooms` แล้วเผยแพร่ Edge Function `chess-room`
ตั้ง `VITE_ONLINE_ROOMS=false` ระหว่าง build เพื่อปิดเมนูและเส้นทางจากหน้าเว็บ
รัน `npm test` เพื่อตรวจสิทธิ์อ่านและเขียน การเข้าห้องพร้อมกัน ตาเดินและหมดเวลา

รุ่นแรกเป็นห้องเชิญแบบไม่จัดอันดับ ไม่มีเวลาทดเพิ่ม ผู้ชม หรือรีแมตช์
