# Phase 6C · ฝึกเปิดเกม

เปิดเมนู **ฝึกเปิดเกม** จากหน้าเล่นกับบอท เลือกฝ่าย แล้ววาง PGN เปิดไฟล์ PGN
หรือใช้เกมที่เคยรีวิวในเครื่อง เกมในคลังออนไลน์นำมาฝึกได้ด้วยปุ่ม **ส่งออก PGN**
ในหน้าบัญชี แล้วเปิดไฟล์ในหน้าฝึก

ระบบใช้ 8 ตาแรกต่อฝ่ายจาก main line ของแต่ละเกมที่เริ่มจากตำแหน่งมาตรฐาน
หาก PGN มีหลายเกม ระบบจะแยกไลน์และรวมไลน์ที่เดินเหมือนกัน
หากต้องการฝึก variation ให้แยกเป็นเกม PGN อีกเกมหนึ่ง

ตอบโดยเดินบนกระดานหรือพิมพ์ SAN/UCI เช่น `Nf3` หรือ `g1f3`
โหมด **ยืดหยุ่น** รับทุกตาที่อยู่ในเกมที่นำเข้าและมาจากตำแหน่งเดียวกัน
โหมด **จำไลน์** รับเฉพาะตาจากไลน์ที่เลือก ผลฝึกของสองโหมดเก็บแยกกัน
ถ้าเลือกตาจากไลน์อื่น ข้อถัดไปยังมาจากไลน์ที่เลือก
คะแนนวัดการตอบตรงกับชุดฝึกโดยเทียบกับ PGN แล้วนัดทบทวนใน 1, 2, 4, 8 และ 16 วัน
หากตอบผิด ระบบให้ทบทวนอีกครั้งใน 10 นาที ความคืบหน้าเก็บในเบราว์เซอร์นี้

ตั้ง `VITE_OPENING_TRAINER=false` ตอน build เพื่อปิดหน้าและเมนู

## สาธิต

1. เปิด **ฝึกเปิดเกม** วาง `1. e4 e5 2. Nf3 Nc6 *` เลือกขาว แล้วกดสร้างชุดฝึก
2. ตอบ `e4` แล้วกดตาถัดไป จากนั้นตอบ `Bc4` เพื่อดูตาตัวอย่าง `Nf3` และคะแนน 50%
3. รีเฟรชหน้า ตรวจว่าคะแนนยังเป็น 50% และยังไม่มีตาที่ถึงกำหนดฝึก
