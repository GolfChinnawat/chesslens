# Phase 6E · ติดตั้งและใช้ ChessLens ออฟไลน์

เปิดหน้าเล่นกับบอทขณะออนไลน์ รอข้อความ **โหลดไฟล์แล้ว · เล่นได้แม้ไม่มีเน็ต**
บรรทัด **การเชื่อมต่อ** แสดงสถานะที่เบราว์เซอร์รายงาน ส่วนข้อความ **โหลดไฟล์แล้ว** บอกความพร้อมของแอป
เว็บจะเตรียมไฟล์แอปและ Stockfish ประมาณ 8 MB ไว้ในเบราว์เซอร์

- ใช้ปุ่ม **ติดตั้ง ChessLens** หรือเมนูติดตั้งแอปของเบราว์เซอร์
- บน iPhone เปิดเว็บใน Safari แล้วเลือก **แชร์ → เพิ่มไปยังหน้าจอโฮม**
- หลังเตรียมเสร็จ เล่นกับ Stockfish นำเข้า PGN และเปิดรีวิวที่บันทึกในเบราว์เซอร์นี้ได้โดยไม่ต่อเน็ต
- บัญชี คลังบน Supabase และการค้นหาเกมสาธารณะต้องเชื่อมต่ออินเทอร์เน็ต
  หากต้องการเปิดเกมจากคลังตอนออฟไลน์ ให้ส่งออก PGN เก็บไว้ก่อน

## สาธิต

1. เปิดหน้าเล่นรอจนโหลดไฟล์แล้ว · เล่นได้แม้ไม่มีเน็ต แล้วลองรีวิว PGN หนึ่งเกม
2. ตัดการเชื่อมต่อ รีเฟรชหน้าเล่น เดินหมากและรอ Stockfish ตอบ
3. เปิดหน้ารีวิว ตรวจว่าเห็นรีวิวที่บันทึกไว้และเดินดูตำแหน่งย้อนหลังได้

ระบบอัปเดตไฟล์ออฟไลน์เมื่อกลับมาออนไลน์ ไฟล์รุ่นใหม่จะเริ่มใช้เมื่อปิดแท็บเดิมทุกแท็บแล้วเปิดใหม่

## ทดสอบ

หลัง `npm run build` ให้เสิร์ฟ `dist/` แล้วรัน `python tests/e2e/offline.py`
โดยตั้ง `CHESSLENS_TEST_URL` ให้ตรงกับ URL ที่เสิร์ฟ และติดตั้ง Playwright Chromium ไว้ก่อน
