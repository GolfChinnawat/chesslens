# Phase 6D · โจทย์จากเกมที่รีวิว

เปิด **โจทย์หมากรุก** จากหน้าเล่น รีวิว หรือบัญชี เลือกฝ่ายและกด **สร้างโจทย์**
หน้าโจทย์ใช้รีวิวในเครื่องและเกมล่าสุดสูงสุด 20 เกมในคลังเมื่อเข้าสู่ระบบ
Stockfish ตรวจผู้สมัครสูงสุด 15 ตำแหน่งที่ depth 16 ด้วย MultiPV 2 แล้วคืนสูงสุด 8 ข้อ
ตำแหน่งที่ไม่พบคำตอบเด่นชัดจะถูกข้าม

ชุดนี้ให้หาตาแรกของแนวรุกฆาตหรือแนวที่ได้หมาก เล่นบนกระดานแล้วเลือกดูเฉลย
หรือเปิดรีวิวต้นฉบับที่ตานั้นได้ ระบบสร้างชุดใหม่เมื่อกดปุ่มและเก็บชุดไว้ในหน้าที่เปิดอยู่

## สาธิต

นำเข้า `1. f3 e5 2. g4 Nc6 *` ในหน้ารีวิวแล้วเริ่มวิเคราะห์
เปิดหน้าโจทย์ เลือกดำ แล้วกดสร้างโจทย์ จากนั้นเดินควีนจาก d8 ไป h4
แล้วเปิดเกมต้นฉบับเพื่อตรวจตาที่พลาด

ตั้ง `VITE_PUZZLES=false` ขณะ build เพื่อปิดหน้าและเมนู
