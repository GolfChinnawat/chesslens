# ChessLens

ChessLens ให้เล่นหมากรุกกับ Stockfish และรีวิวเกมจาก PGN ผ่านเบราว์เซอร์ในภาษาไทย

## ติดตั้งและรัน

ใช้ Node.js 20.19+ ในสาย 20 หรือ 22.12 ขึ้นไป พร้อม npm

```sh
npm ci
npm run dev
```

เปิด URL ที่ Vite แสดง เลือกสีและระดับบอท แล้วกด **เกมใหม่** เดินหมากด้วยการลาก หรือคลิกหมากแล้วคลิกช่องปลายทาง การย้อนตาจะลบตาล่าสุดของคุณและตาที่บอทตอบกลับ ถ้าคุณเล่นดำ ตาเปิดของบอทจะยังอยู่

เกมจะบันทึกอัตโนมัติในเบราว์เซอร์เดิมเมื่ออนุญาต localStorage ส่งออกเกมด้วย **คัดลอก PGN** หรือ **ดาวน์โหลด PGN** การคัดลอกต้องเปิดผ่าน localhost หรือ HTTPS ในเบราว์เซอร์ที่รองรับ Clipboard API

## รีวิวเกม

เลือก **รีวิวเกม** แล้ววาง PGN อัปโหลดไฟล์ `.pgn` หรือใช้เกมที่เพิ่งเล่น เลือกเกมและความลึก แล้วกด **เริ่มวิเคราะห์** เลือกตาจากกระดานควบคุม กราฟ หรือรายการเดินได้ และใช้ปุ่มลูกศรซ้าย/ขวา หรือ Home/End ได้ ผลที่วิเคราะห์เสร็จจะเปิดอีกครั้งได้ในเบราว์เซอร์เดิม

หน้ารีวิวแสดงป้ายคุณภาพการเดินและความแม่นยำของทั้งสองฝ่าย กด **ไปยังตาพลาดถัดไป** แล้วเลือก **ลองเดินใหม่** เพื่อทดลองตาทางเลือก เกณฑ์อยู่ใน [Classification](docs/CLASSIFICATION.md)

ลิงก์ **ทดสอบ Stockfish** เปิดหน้าทดสอบเอนจินจาก Phase 0

```sh
npm run lint
npm test
npm run build
npm run preview
```

หลัง `npm run preview` ลองเดินหมากและรอให้บอทตอบ เพื่อยืนยันว่า Worker และ WASM โหลดจาก `dist/` ได้ การเผยแพร่ใช้ static HTTP(S) server ที่เสิร์ฟไฟล์ WASM ด้วย MIME type `application/wasm` เอนจินโหลดจากเซิร์ฟเวอร์เดียวกันและใช้เธรดเดียว

### ลองใช้ Phase 4

เปิด **รีวิวเกม** จากนั้นค้นหาชื่อผู้ใช้สาธารณะใน Chess.com หรือ Lichess
เลือกเกมและตั้งค่าความลึกกับจำนวนแนวเดิน แล้วกด **เริ่มวิเคราะห์**
ตำแหน่งที่คำนวณแล้วจะเปิดดูได้ระหว่างที่ Stockfish ทำงานต่อ

เมื่อตรวจเกมเสร็จ เลือก **ฝึกจากตาพลาด** แล้วเลือกฝ่าย หากนำเข้าจากชื่อผู้ใช้
ระบบจะเลือกฝ่ายให้อัตโนมัติเมื่อชื่อตรงกับข้อมูลเกม ใช้ **คำใบ้** ดูช่องต้นทาง
หรือกด **เฉลย** ดูลูกศรแนวเดินก่อนข้ามไปข้อถัดไป

ในรายการเดินมีชื่อป้าย เช่น **Best**, **Good** และ **Blunder** กำกับ
เปิด **โหมดวางแผน** เพื่อคลิกซ้ายเลือกหมากและช่องปลายทางหรือลากหมาก
และคลิกขวาค้างแล้วลากเพื่อวาดลูกศร กด **กลับไปดูเกมจริง** เพื่อออกจากแนวที่ลอง

ชื่อเปิดเกมอ้างอิงฐานข้อมูล ECO ที่ฝังไว้ในเว็บ การวิเคราะห์ตำแหน่งเพิ่ม
ใช้ Worker เธรดเดียว กำหนดเวลาได้สูงสุด 12 วินาทีต่อคำขอ และหยุดได้ด้วยปุ่ม **หยุด**
การนำเข้าขึ้นอยู่กับการตอบกลับของ API สาธารณะ หากบริการปฏิเสธคำขอ ยังใช้ PGN ได้

### บัญชีและคลังเกมออนไลน์

Phase 5 รุ่นแรกเพิ่มบัญชี คลังรีวิว สถิติจากเกมที่บันทึก และชุดฝึกตามกำหนด
ฟีเจอร์ออนไลน์เปิดขึ้นเมื่อกำหนด Supabase สำหรับเว็บไซต์
ดู [วิธีตั้งค่าและ deploy](docs/DEPLOY.md) และ [แบบจำลองข้อมูล](docs/ACCOUNTS.md)

Phase 6C เพิ่มตัวฝึกเปิดเกมจาก PGN และเกมที่เคยรีวิว พร้อมสถิติแยกไลน์และรอบทบทวน ([วิธีใช้](docs/OPENING_TRAINER.md))

Phase 6D รุ่นแรกสร้างโจทย์รุกฆาตและชนะหมากจากเกมที่รีวิว พร้อมเปิดเกมต้นฉบับ ([วิธีใช้](docs/PUZZLES.md))

Phase 6E เพิ่มการติดตั้ง ChessLens และใช้งานออฟไลน์ ([วิธีติดตั้ง](docs/OFFLINE.md))

Phase 6F รุ่นแรกเพิ่มข้อมูลสำหรับค้นหาและแชร์ลิงก์ และแสดงสถานะการเชื่อมต่อควบคู่กับความพร้อมใช้งานออฟไลน์

ดู [วิธีร่วมพัฒนาและแจ้งบั๊ก](CONTRIBUTING.md)

Phase 6A รุ่นแรกเพิ่มคำอธิบายภาษาไทยสำหรับทุกตาที่วิเคราะห์แล้วในหน้ารีวิว ใช้ผล Stockfish และข้อมูลกระดานในเบราว์เซอร์
